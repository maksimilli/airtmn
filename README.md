# Каталог электронных компонентов

Каталог диодов: импорт PDF, ручное добавление, карточка компонента, редактирование, поиск по имени, производителю, корпусу и характеристикам с учётом типа значения и условий. React + TypeScript, FastAPI, SQLite. Данные и PDF сохраняются в `data/` относительно рабочей директории сервера; можно переопределить `CATALOG_DATA_DIR`.

## Установка

Из корня репозитория (Python 3.12+, Node 22+):

```bash
UV_CACHE_DIR=/workspace/.uv-cache uv venv .venv
UV_CACHE_DIR=/workspace/.uv-cache uv pip install --python .venv/bin/python -r backend/requirements.txt
npm ci --prefix frontend --cache /workspace/.npm-cache
```

## Запуск

Два терминала из корня репозитория:

```bash
.venv/bin/python -m uvicorn app.main:app --app-dir backend --host 0.0.0.0 --port 8000
```

```bash
npm run dev --prefix frontend
```

Frontend использует Vite proxy `/api` к серверу на порту 8000.

## Проверки

```bash
PYTHONPATH=backend .venv/bin/python -m pytest backend/tests -q
npm run build --prefix frontend
npm test --prefix frontend
curl --fail http://127.0.0.1:8000/api/health
```

## Поддерживаемые характеристики

VRRM, VRMS, VDC, IF(AV), IFSM, VF, IR, CJ, PD и TRR. Числовые значения нормализуются в V, A, F, W, s. В интерфейсе можно выбрать удобные единицы: mA, µA, pF, ns и другие. Запятая и точка поддерживаются. Min, typ, max и значения без указанного типа хранятся отдельно; при ручном вводе тип нужно выбрать самостоятельно.

Карточка открывается нажатием на обозначение в каталоге. В ней видны все параметры, условия, документ и страницы-источники. Кнопка «Редактировать» обновляет существующую запись, сохраняя её идентификатор и документ. Фрагменты источника остаются исходными, даже если пользователь исправляет значение.

В дополнительных фильтрах можно выбрать одну характеристику, её тип, единицу, нижнюю/верхнюю границу и подстроку условий. Все эти требования проверяются для одного и того же значения; типовое значение не подменяет максимальное. Поиск условий — текстовый поиск, а не интерпретация физических режимов; например, используйте `TA = 25 °C`, а не просто `25`.

## Импорт и ограничения

Парсер поддерживает таблицы RATINGS / CHARACTERISTICS с отдельными колонками моделей и физически объединёнными общими ячейками. Для документа с одной моделью в первой строке поддерживаются отдельные колонки MIN / TYP / MAX. В электрических таблицах тип также определяется по словам Maximum, Minimum, Typical в описании; неоднозначный тип остаётся «Не указано». Сохраняются условия, страницы и исходные фрагменты. Также читаются явно записанные символ, значение и единица на одной строке.

Для семейства выберите нужную модель. Производитель распознаётся по явному упоминанию Vishay, Nexperia, Diodes Incorporated, onsemi или STMicroelectronics на первой странице; корпус — из строки Case. Это не универсальный парсер PDF: безлинейные таблицы, сложные многоуровневые заголовки и произвольные обозначения могут не распознаться. Все извлечённые значения требуют проверки.

На предоставленном Vishay 1N4001–1N4007 проверены 7 моделей и 12 значений для каждой: обратные напряжения, средний и импульсный ток, прямое напряжение, обратный ток при двух температурах, типовая ёмкость. Таблицы MIN/TYP/MAX и отличия пустой ячейки от объединённой покрыты синтетическими тестовыми PDF. Качество на документах других производителей ещё не измерялось.

OCR, другие категории и PostgreSQL пока не реализованы. PDF ограничены 20 МБ и 200 страницами. Приложение предназначено для локального использования, без аутентификации. Схема существующей SQLite-базы совместима: обновление добавляет только индекс поиска, не удаляя записи и документы.

## Windows без программирования

На странице GitHub нажмите **Code → Download ZIP**, распакуйте весь архив. Установите Python 3.12 или новее с https://www.python.org/downloads/windows/ и отметьте **Add python.exe to PATH**. Дважды нажмите `START_WINDOWS.bat`. При первом запуске нужен интернет для установки зависимостей. Браузер откроется автоматически; чёрное окно оставьте открытым. Подробная инструкция и пример проверки — в `WINDOWS_README.txt`.

Собранный интерфейс `frontend/dist` включён в репозиторий для запуска на Windows без Node.js. После изменений интерфейса выполните `npm run build --prefix frontend` и обновите эти файлы. Windows-скрипт пока не проверен на настоящей Windows; содержимое пакета и API проверены в облачной Linux-среде.

## Обновление Windows-версии

Остановите приложение (Ctrl+C в чёрном окне), распакуйте новую версию в новую папку. Для переноса записей скопируйте **всю папку data** из старой версии в новую; не удаляйте старую папку до проверки. Запустите START_WINDOWS.bat. Прежние значения автоматически не дополняются новым импортом: откройте карточку и исправьте их вручную либо добавьте новую модель из документа.
