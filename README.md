# Элемент — каталог электронных компонентов

Локальное приложение: FastAPI + SQLite + React/TypeScript. PDF автоматически заполняет проверяемый черновик; пользователь сохраняет карточку после проверки. Исходные PDF и база находятся в `data/`, путь можно изменить через `CATALOG_DATA_DIR`.

[Техническое описание: архитектура, распознавание, база, API и демонстрация](docs/TECHNICAL_GUIDE.md)

## Разделы и функции

10 категорий: диоды, полевые и биполярные транзисторы, микросхемы, резисторы, конденсаторы, индуктивности, соединители и переключатели, источники питания, прочие компоненты. Каждая имеет свой набор характеристик, единиц, формы добавления, редактирования и поиска.

Обзор библиотеки, каталог, импорт с предпросмотром PDF, карточка, документы, сравнение до четырёх компонентов одного раздела, CSV-экспорт и справка. Все счётчики используют реальные записи. Учебные примеры автоматически в каталог не добавляются.

При уверенном определении другого типа PDF импорт блокируется **до сохранения документа**. Интерфейс объясняет причину и предлагает повторить загрузку в правильном разделе. Если тип неоднозначен, отображается предупреждение; категория требует ручной проверки.

## Windows

1. Распакуйте весь архив в новую папку.
2. Установите **Python 3.12 (64-bit)**: https://www.python.org/downloads/release/python-31210/ → Files → Windows installer (64-bit). Оставьте Python Launcher.
3. Дважды нажмите `START_WINDOWS.bat`. При установке зависимостей нужен интернет. Браузер откроется автоматически, чёрное окно оставьте открытым.
4. Ctrl+C завершает приложение.

Скрипт выбирает Python 3.12, сохраняя другие установленные версии и прежнюю среду. При необходимости создаёт `.venv-windows-312`. Текущий OCR не поддерживает Python 3.13/3.14. Node.js пользователю не нужен: `frontend/dist` включён в архив. Подробности — `WINDOWS_README.txt`.

Для обновления закройте приложение, распакуйте новую версию и скопируйте **всю папку `data`** из старой версии. Старая база дополняется столбцами без удаления карточек, идентификаторов или PDF; прежние компоненты получают категорию «Диоды». Не удаляйте старую папку до проверки.

Выбор Python и обработка ошибок установки покрыты тестами; новый интерфейс и API проверяются в облачной Linux-среде. Полный запуск нового пакета на настоящей Windows требует проверки на компьютере пользователя.

## Разработка

Из `/workspace/airtmn` (Python 3.12, Node 22+):

```bash
UV_CACHE_DIR=/workspace/.uv-cache uv venv --python 3.12 --allow-existing .venv
UV_CACHE_DIR=/workspace/.uv-cache uv pip install --python .venv/bin/python -r backend/requirements.txt
npm ci --prefix frontend --cache /workspace/.npm-cache
```

Сервер и интерфейс в отдельных терминалах:

```bash
.venv/bin/python -m uvicorn app.main:app --app-dir backend --host 0.0.0.0 --port 8000
```

```bash
npm run dev --prefix frontend
```

Vite перенаправляет `/api` к порту 8000. Python также отдаёт собранный интерфейс — этот режим используется в Windows. Перед публикацией изменений интерфейса пересоберите и обновите tracked `frontend/dist`.

```bash
PYTHONPATH=backend .venv/bin/python -m pytest backend/tests -q
npm test --prefix frontend
npm run build --prefix frontend
curl --fail http://127.0.0.1:8000/api/health
```

## Извлечение и ограничения

Цифровой PDF разбирается напрямую через PyMuPDF. Для сканов используется локальный RapidOCR/ONNX Runtime с моделями из зависимости, без ключей и внешних сервисов. В автоматическом режиме уже найденные цифровые параметры сохраняются. Принудительный OCR предназначен для плохого текстового слоя.

Поддерживаются таблицы SYMBOL, MIN/TYP/MAX без SYMBOL, каталоги с моделями в строках, таблицы PARAMETER/SPECIFICATIONS, таблицы без линий и явно подписанные характеристики на чертежах. Словарь содержит 58 характеристик. Значения связываются с физическими строками, колонками, условиями и конкретными моделями; пустая ячейка не заполняется соседним числом. Повреждённые единицы в текстовом слое (например, потерянный символ µ в µA) требуют OCR, даже если остальные числа читаются.

[Отчёт проверки 47 PDF из data1.zip и способ повторить проверку](docs/DATASHEET_VALIDATION.md)

Сохраняются тип, условия, страница, фрагмент и источник. Числа нормализуются в базовые единицы, интерфейс показывает удобные единицы и принимает запятую/точку. Ручная правка очищает оценку OCR. Фильтры проверяют один параметр с выбранными типом, границами и условиями. Условия сравниваются как текст, без физической интерпретации.

PDF ограничен 20 МБ и 200 страницами, OCR — 10 страницами и 12 млн пикселей на страницу при 240 DPI. Сложные и безлинейные таблицы, нетипичные обозначения, наклон и плохое качество могут привести к пропускам. Это не универсальное распознавание всех характеристик любого PDF. Значения нужно сверять с оригиналом; низкая оценка OCR подсвечивается, высокая оценка не гарантирует правильность.

Предоставленный Vishay 1N4001–1N4007 используется для проверки соответствия 7 моделям и 12 значениям на каждой модели. Новые категории и блокировка типа проверяются синтетическими примерами. Качество на реальных Datasheet других производителей и всех новых категорий пока не измерено; для конкретного сбоя требуется сам файл.

Учебные PDF в `examples/` содержат **вымышленные** компоненты. Они служат для проверки действий интерфейса и не предназначены для проектирования.

Приложение рассчитано на локальное использование: без аутентификации, PostgreSQL, PLM-интеграции и корпоративного многопользовательского режима.
