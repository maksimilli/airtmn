ЭЛЕМЕНТ — КАТАЛОГ ЭЛЕКТРОННЫХ КОМПОНЕНТОВ

ЗАПУСК
1. Распакуйте весь архив в отдельную папку, не запускайте из ZIP.
2. Установите Python 3.12 (64-bit):
   https://www.python.org/downloads/release/python-31210/
   Files → Windows installer (64-bit) → Install Now.
   Оставьте включённым Python Launcher. Другой Python удалять не нужно.
3. Дважды нажмите START_WINDOWS.bat. Для установки нужен интернет.
4. Браузер откроется автоматически. Чёрное окно оставьте открытым.
5. Для завершения нажмите Ctrl+C в чёрном окне.

ПЕРВАЯ ПРОВЕРКА
Выберите «Резисторы» и нажмите «Загрузить PDF».
Выберите файл examples\DEMO_RESISTOR.pdf.
Автоматически заполнятся: R 10 kΩ, PD 0.25 W, TOL 5 %.
Нажмите «Сохранить проверенный компонент» и откройте карточку.
Эти компоненты и значения вымышлены — только для демонстрации.
Другие примеры: DEMO_CAPACITOR.pdf, DEMO_MOSFET.pdf,
DEMO_INDUCTOR.pdf и скан DEMO_DIODE_SCAN.pdf.

ПРОВЕРКА КАТЕГОРИИ
На странице резисторов попробуйте загрузить DEMO_DIODE_SCAN.pdf
или даташит диода. При определении диода загрузка блокируется.
Нажмите предложенную кнопку для загрузки в раздел «Диоды».
Если тип документа не определён уверенно, проверьте категорию сами.

РАБОТА С КАТАЛОГОМ
Выберите категорию слева. В каждой есть поиск и отдельные параметры.
«Добавить вручную» открывает форму. Нажмите «Добавить характеристику».
Можно вводить запятую и точку: 0,5 или 0.5. Выбирайте единицу и тип.
В дополнительных фильтрах задайте характеристику, min/typ/max,
единицу, границы и текст условий; затем нажмите «Найти».
В карточке нажмите «Редактировать» для изменения существующей записи.
Удаление карточки требует подтверждения; PDF остаётся в документах.
Отметьте до четырёх компонентов одного раздела для сравнения.
Кнопка «Экспорт раздела» скачивает CSV, который открывается в Excel.

ИМПОРТ
Выберите PDF и дождитесь заполнения формы. Для семейства выберите
модель в списке. Справа виден исходный PDF, можно переключать страницы.
Обычный PDF читается напрямую. «Автоматически» включает OCR для сканов.
«OCR всех страниц» используйте для повреждённого текстового слоя.
Нечитаемые сканы и сложные таблицы могут не распознаться полностью.
Все значения и условия нужно сверять с исходником перед сохранением.
PDF: до 20 МБ и 200 страниц. OCR: до 10 страниц за загрузку.
Файл сохраняется локально, онлайн-сервисам не отправляется.

ОБНОВЛЕНИЕ И ДАННЫЕ
Закройте старую версию, распакуйте новую в новую папку.
Скопируйте всю папку data из старой версии в новую.
Не удаляйте старую папку до проверки переноса.
Скрипт сам выберет совместимый Python 3.12 и обновит зависимости.
Python 3.13/3.14 текущей библиотекой OCR не поддерживаются.

ТЕХНИЧЕСКОЕ ОПИСАНИЕ
Файл docs\TECHNICAL_GUIDE.md содержит архитектуру, схему базы,
путь данных от PDF до карточки, описание API и сценарий демонстрации.
Markdown можно открыть обычным текстовым редактором или на GitHub.

Node.js и права администратора для запуска не требуются.
Если произошла ошибка, пришлите фотографию текста в чёрном окне.
