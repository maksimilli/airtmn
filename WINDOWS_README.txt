КАТАЛОГ ЭЛЕКТРОННЫХ КОМПОНЕНТОВ — ЗАПУСК НА WINDOWS

1. Распакуйте весь ZIP-архив в отдельную папку (не запускайте из архива).
2. Установите Python 3.12 или новее с https://www.python.org/downloads/windows/
   При установке отметьте Add python.exe to PATH.
3. Дважды нажмите START_WINDOWS.bat.
   При первом запуске дождитесь установки зависимостей — нужен интернет.
4. Браузер откроется автоматически. Оставьте чёрное окно открытым.
   Если браузер не открылся, введите http://127.0.0.1:8000 в адресной строке.
5. Чтобы завершить работу, нажмите Ctrl+C в чёрном окне.

БЫСТРАЯ ПРОВЕРКА
Нажмите «Добавить вручную». В обозначении введите TEST100.
Нажмите «+ Характеристика»: выберите VRRM, введите 100.
Добавьте ещё характеристику: IF(AV), значение 0.5.
Нажмите «Сохранить проверенный компонент».
Введите TEST в поиске и нажмите «Найти» — появится ваша запись.
В поле IF(AV) от введите 1 и нажмите «Найти» — запись исчезнет,
так как её допустимый ток равен 0.5 А.

Для импорта нажмите «Загрузить PDF», выберите Datasheet и проверьте
результат перед сохранением. Пока распознаются только явно записанные
VRRM и IF(AV); сканы и сложные таблицы ещё не поддерживаются.

Данные сохраняются в папке data рядом с файлом запуска.
Не удаляйте эту папку, если хотите сохранить записи и документы.
Node.js не требуется: интерфейс уже собран и входит в архив.
Права администратора для запуска приложения не нужны.
Если произошла ошибка, пришлите фотографию текста в чёрном окне.
