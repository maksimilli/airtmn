# Бесплатная демонстрация на Hugging Face Spaces

Этот вариант запускает портал в Docker Space на CPU Basic. Внешняя регистрация
посетителям не нужна; только администратор может добавлять и изменять компоненты.
HTTPS предоставляет Hugging Face. VPS, отдельный домен и Caddy не требуются.

## Настройка через браузер

1. Откройте свой Space, например `https://huggingface.co/spaces/Maximkrutoy/datasheet`.
2. В **Settings** найдите **Variables and secrets**. Нажмите **New secret**:
   имя `CATALOG_ADMIN_PASSWORD`, значение — придуманный пароль от 12 до 200 символов.
   Сохраните его у себя. Не отправляйте пароль в чат и не добавляйте в файлы.
3. Нажмите **New variable**: имя `CATALOG_PUBLIC_ORIGIN`, значение
   `https://maximkrutoy-datasheet.hf.space` без завершающего `/`.
   Для другого Space используйте его прямой адрес из **Embed this Space**.
4. Скачайте `Dockerfile` и `README.md` из `deploy/huggingface` этого репозитория.
   Если используете ZIP-пакет, сначала распакуйте его: загружаются два файла, а не ZIP.
5. Перейдите в **Files → Add file → Upload files**, загрузите оба файла в корень
   Space и нажмите **Commit changes**. Если `README.md` уже есть, замените его.
   Поле `sdk: docker` в новом README переключает прежний Static Space на Docker;
   `app_port: 7860` указывает порт Python-приложения. Прежний `index.html` можно оставить,
   он больше не используется. Не помещайте файлы в подпапку.
6. Дождитесь **Building → Running**. При ошибке откройте **Logs**:
   сборка устанавливает зависимости, а запуск проверяет наличие пароля администратора.
7. Откройте `https://maximkrutoy-datasheet.hf.space` отдельной вкладкой, нажмите
   **Войти**, введите `admin` и свой пароль. При открытии внутри рамки Hugging Face
   браузер может блокировать cookie входа. Публичный просмотр не требует входа.

Не переключайте Hardware на платный тариф. На момент подготовки предлагается
бесплатный CPU Basic; проверьте обозначение стоимости в интерфейсе платформы.

## Как работает пакет

В Space загружаются только Dockerfile и README. Dockerfile скачивает публичный
архив проекта, закреплённый на коммите `6d806efb933603a3d792629a661ad587457b5e9d`,
проверяет SHA256, устанавливает зависимости Python 3.12 и запускает FastAPI на
порту 7860. Собранный React-интерфейс уже находится в архиве; Node.js не требуется.
Контейнер работает от UID 1000, пароль поступает из секрета только при запуске.
Распознавание PDF выполняется локально в контейнере через PyMuPDF и RapidOCR.

Пакет проверен локально в Docker: сборка, запуск от UID 1000, загрузка интерфейса,
запрет записи посетителям, вход администратора, Secure cookie, запрет запросов
с чужого сайта, извлечение и сохранение исходного `1n4001.pdf`, инициализация моделей
OCR. Фактическая сборка и запуск на Hugging Face проверяются после загрузки файлов
и настройки секрета владельцем Space.

Сайт принудительно работает в серверном режиме с Secure cookie. Удаление секретного
пароля из настроек не открывает права посетителям: новая пустая база без пароля
не запустится. При смене пароля в настройках уже существующая учётная запись
не перезаписывается. Пароли действующих пользователей меняются в интерфейсе
администраторов; сброс через серверную консоль описан в инструкции VPS.

## Данные и ограничения

SQLite и PDF находятся в `/data/catalog`. На бесплатном Space файловая система
временная: данные могут потеряться при пересборке, factory reboot или пересоздании
среды. Пробуждение после простоя может занять время; распознавание больших PDF
занимает ресурсы и не гарантирует заполнение каждого параметра.

Не переносите единственную копию рабочего каталога в бесплатный Space.
Сохраните исходную папку `data` на компьютере. Этот пакет запускается с пустым
каталогом, не публикует локальную базу, аккаунты или прикреплённые пользователем PDF.
Установка шаблона не переносит автоматически уже существующие компоненты.

Для обновления демо укажите в Dockerfile новый опубликованный коммит и SHA256 его
архива, затем загрузите обновлённый Dockerfile в Space. Установка нового шаблона
может пересоздать среду и очистить временный каталог.

Для постоянной работы используйте [инструкцию сервера](SERVER_DEPLOYMENT.md)
или отдельно спроектированное постоянное хранилище. Обычный Docker volume на VPS
и временный диск бесплатного Space имеют разные гарантии сохранности.
